# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1, as its code of conduct.

The canonical text lives at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and applies in full to all project spaces — issues, pull requests, discussions, commit messages, and any other channel run under this repository.

## Scope

The covenant applies when an individual is officially representing the project or its community in public spaces.

## Reporting

Report unacceptable behavior to the maintainers via GitHub's private vulnerability reporting flow:
<https://github.com/williamzujkowski/cf-knowledge-kiln/security/advisories/new>.
Reports are confidential to the maintainers and will be reviewed within 72 hours.

Security issues follow the same private channel — see [SECURITY.md](./SECURITY.md).
